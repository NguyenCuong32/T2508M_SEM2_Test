# HeroGame

JDK required: `17`

Quick start:
1. Open XAMPP.
2. Start `MySQL`. Start `Apache` too if you want phpMyAdmin.
3. Open this project in IntelliJ IDEA as a Maven project.
4. Click the shared run configuration `Run HeroGame`.

Notes:
- The app automatically creates and initializes the `HeroGame` database on startup.
- No manual SQL import is needed.

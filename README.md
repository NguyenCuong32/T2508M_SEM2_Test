# T2508M_SEM2_Test

Programming with C# - SET01 practical solution.

## Projects

- `BankAccountConsole`: console application for normal and exchange bank accounts.
- `ProductViewerWinForms`: Windows Forms application that reads `product.json` and shows products in a table.

## Run

```powershell
dotnet run --project BankAccountConsole
dotnet run --project ProductViewerWinForms
```

## Build

```powershell
dotnet build T2508M_SEM2_Test.sln
```
